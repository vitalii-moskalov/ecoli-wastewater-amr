# Original AMRFinderPlus annotations

The original, per-assembly output files for 132 publicly available wastewater-derived *Escherichia coli* assemblies are stored without editing:

- [`Germany/`](Germany/): 92 TSV files (PRJNA380388).
- [`Sweden/`](Sweden/): 40 TSV files (PRJNA1266621).

AMRFinderPlus **4.2.7**, database **2026-10-29.1**; the recorded organism setting was `Escherichia` with the `--plus` option.

`ecoli_amrfinder_132_file_checksums.csv` records SHA-256 values of the archived 132 TSV files. Hash matching for the local archive does not by itself prove that every GitHub copy has been independently checked.

The retained hits, explicit exclusion log and presence matrices are stored in [`../derived/`](../derived/). They are **filtered derivatives**, not the raw annotations. Original NCBI assemblies can be retrieved by accession and are not reproduced here.
